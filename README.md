# OmniCAD website

This version is rebuilt directly from the supplied OmniLayout `index.html` visual system rather than from a separate website template. The original OmniLayout CSS/classes, shell width, navigation, hero, showcase, benchmark, statistics, quantitative-table, author, citation, theme-toggle, and footer patterns are retained. Only OmniCAD content/assets are substituted.

## Add the qualitative video
Place your video at:

`public/media/3D-interaction.mp4`

Recommended web export: 5120×960, H.264, CRF 16, `faststart`.

`res/omnicad_code.zip` and `res/omnicad_samples.zip` are intentionally empty valid ZIPs for later replacement.
