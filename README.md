# OmniCAD project website

Static GitHub Pages site built from the supplied OmniLayout-style page and current OmniCAD manuscript.

## Deploy
1. Create a repository such as `OmniCAD_web`.
2. Upload the contents of this folder so `index.html` is at repository root.
3. GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
4. The URL will be `https://<username>.github.io/OmniCAD_web/`.

## Before public release
- Replace the placeholder author/institution section.
- Replace the placeholder BibTeX with the final arXiv/publication record.
- Update the Code URL if the public repository changes.
- Add the final Dataset/Hugging Face/Zenodo link.

## Do I need the experiment/processing source code?
No, not to build the website. The site can simply link to your existing GitHub code repository. Send the source code only if you want downloadable code archives, API/CLI documentation, code examples, or interactive demos embedded into the project page.
